-DeadCore Level Editor Mod Prototype-
Requires: MelonLoader, DeadCore Redux on Steam

Installation:
1- Download MelonLoader Installer from their Official Github Page and the Mod Release from this Repo.
2- Open Installer and Click the DeadCoreRedux Option, Click Install.
3- Open Your DeadCore Redux Steam "common" Folder.
4- Copy the Mod Release to the newly created "Mods" Folder.
5- Open the game.

Controls:
F1: Open Editor
F5: Save Level
F6: Load Last Level (WARNING: Overwrites the Current Level, use Menu Loading Instead)
WASD: Move Camera
Right Click: Rotate Camera
Mouse Wheel: Browse Wheel Assets
TAB: Switch Asset Tab (Essentials, Extracted, Misc)
Enter: Enter Placing Mode
Backspace: Exit Placing Mode
Left Click: Place Selected Wheel Asset
Shift + Mouse Wheel: Scale Asset / Change Asset Properties

Creating your First Level:
1-Click the new Level Editor Button on the Main Menu.
2-Click "New Level", then press "Play".
3-Once in game, Press F1 and start creating, check controls for quick start.
